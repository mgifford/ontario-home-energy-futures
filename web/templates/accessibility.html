Accessibility

Ontario Home Energy Futures targets WCAG 2.2 Level AA. Full detail, including the manual test checklist and accessibility decision record, is in ACCESSIBILITY.md in the source repository.

Supported input methods

  • Full keyboard operation
  • Screen readers
  • Browser zoom to 200% and reflow at 320 CSS pixels
  • Touch, with minimum target sizes
  • Reduced-motion and high-contrast operating-system settings
  • No JavaScript — methodology, data-source, and standard scenario pages remain fully usable

Known limitations

  • The client-side calculator's live-region announcements have not yet been validated with a screen-reader user outside the project maintainers.
  • Playwright/axe-core automated specs are included but require a local Playwright browser install to execute.
  • A full manual screen-reader pass against a live deployment has not yet been logged for this Phase 1 prototype.

How to report a problem

Open a GitHub issue with the "Accessibility" label, including the page URL, the assistive technology and browser/OS combination if applicable, and the expected versus actual behaviour.
