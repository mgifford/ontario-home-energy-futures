Saved scenario format

A downloaded scenario file can be reloaded later. It has this shape:

{
  "schema_version": "1.0",
  "model_version": "{{ model_version }}",
  "data_cutoff": "{{ data_cutoff }}",
  "region": "Ottawa",
  "utility": "Hydro Ottawa",
  "inputs": {},
  "scenario_ids": [],
  "result_checksum": ""
}

Saved scenario files never include an exact address, an account number, or any other private information in the file or in a shareable URL's query string.
